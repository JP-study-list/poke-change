# kb/img — 知識頁的內文插圖

這個目錄的圖**會進 git**，跟 `img/bg`、`img/extra` 一樣是例外。
理由不同：那兩個是因為來源沒有 CORS 標頭畫不進分享圖，
這裡是因為**知識頁是靜態頁，圖必須跟著頁面一起送出去**。

寶可夢圖示、背卡與符號這些站內已經有的素材不放這裡，
直接連現成的路徑或外部 CDN，不要再複製一份。

## 規格

| 項目 | 值 |
| --- | --- |
| 命名 | `<slug>-<序號>.png`，例 `lucky-trinket-1.png` |
| 寬度 | 720px（縮過的，不要放手機原始截圖） |
| 格式 | 介面截圖用 PNG（文字要銳利），照片類用 JPG |
| 單張 | 200 KB 以內 |
| 引用 | 內文裡寫 `../img/<檔名>` |

**`<img>` 要寫死 `width` 與 `height`**，不然圖載進來的瞬間整頁會往下跳
（CLS，Google 直接拿它算分）。數字填縮完的實際像素。

## 一張圖進來要做的三件事

1. 縮到 720px 寬再放進來
2. 內文裡 `<figure>` 包起來，**一定要有 `<figcaption>`**
3. `alt` 寫這張圖在講什麼，不要寫「截圖」
