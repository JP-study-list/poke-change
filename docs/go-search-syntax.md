# GO 搜尋語法參考

> **這份是外部資料的抄錄，不是本專案的規格。** 程式沒有用到它，
> 收在這裡是為了之後要做「產生搜尋字串」或「站內搜尋支援語法」時不必重查。
>
> 來源：巴哈姆特 Pokémon GO 板〈寶可夢/朋友搜尋篩選條件完整列表〉
> `https://forum.gamer.com.tw/C.php?bsn=29659&snA=32191`（2026-09-17 抄錄）
>
> ⚠️ **單一來源，沒有交叉比對過，而且明顯過時**：地區只列到伽勒爾（八代），
> 沒有帕底亞；沒有背景（背卡）、極巨化與超極巨化的關鍵字。
> 真的要拿來產字串之前，**每一條都要在遊戲裡實測**——
> 這跟「只收確認在 GO 裡有的東西」是同一條原則，
> 產出一個搜不到東西的字串跟列出一個換不到的組合一樣糟。

## 寶可夢搜尋

### 固定字詞

| 字詞 | 意思 |
| --- | --- |
| 雄性／雌性／性別不明 | 對應性別 |
| 異色 | 色違 |
| 亮晶晶 | 交易獲得的 |
| 傳說的寶可夢 | 神獸 |
| 究極異獸 | |
| 幻 | 幻之寶可夢 |
| **特殊** | **戴有裝扮的**（只能篩「有裝扮」，不能指定是哪一個） |
| 孵化 | 蛋孵出來的 |
| 只限蛋 | 寶寶型態 |
| 進化 | 目前可以進化的 |
| 超級進化 | 可以超級進化的 |
| 交換進化 | 交換後進化不用糖果的 |
| 道具 | 要用進化道具的 |
| 未登錄 | 進化後可解鎖圖鑑的 |
| 糖果XL | 用過 XL 糖果升等的 |
| 交換 | 交換得到的 |
| 調查 | 田野調查獎勵（2020/11 之後） |
| Snapshot | AR 拍照亂入獎勵（2020/11 之後） |
| 火箭 | 擊敗火箭隊獎勵（2020/11 之後） |
| **淨化** | 淨化過的 |
| **暗影** | 暗影 |
| 團體戰／VIP團體戰／超級團體戰／遠距團體戰 | 對應團體戰獎勵（2020/11 之後） |
| 防禦者 | 目前占塔中的 |
| GO對戰聯盟 | 聯盟獎勵（2020/11 之後） |

### 名字與編號

- 直接打名字或暱稱，**可以只打前幾個字**
- `+名字` —— 整個家族（例：`+波波`）
- 編號直接打：`150` 是超夢
- 編號區間用 `-`：`1-151`、`152-251`、`252-386`、`387-493`、`494-649`、`650-`

### 地區

關都／城都／豐緣／神奧／合眾／卡洛斯／阿羅拉／伽勒爾（一代到八代）

> 這份清單停在八代。帕底亞與洗翠這些新的沒有列，要自己實測。

### 數值範圍

一律是 `關鍵字下限-上限`，省略一邊就是開區間。

| 寫法 | 意思 |
| --- | --- |
| `cp2000-3000` | CP 2000 到 3000 |
| `cp3000-` | CP 3000 以上 |
| `cp-1000` | CP 1000 以下 |
| `hp20-100` / `hp200-` / `hp-100` | 同理 |
| `日數0` | 24 小時內捕捉 |
| `日數365-` | 超過 365 天 |
| `年2016` | 2016 年捕捉的 |
| `距離200` | 200 公里內 |
| `距離200-` | 超過 200 公里 |
| `夥伴3-4`、`夥伴4-` | 夥伴等級 0~5 |
| `超級2-3`、`超級3-` | 超級寶可夢等級 1~3 |

### 個體值

| 寫法 | 意思 |
| --- | --- |
| `0*` | IV 0～48.9 |
| `1*` | IV 51.1～64.4 |
| `2*` | IV 66.7～80 |
| `3*` | IV 82.2～97.78 |
| `4*` | IV 100 |

三圍各自用 `0-4攻擊`、`0-4防禦`、`0-4HP`：
0 = 0、1 = 1~5、2 = 6~10、3 = 11~14、4 = 15。

### 招式

| 寫法 | 意思 |
| --- | --- |
| `@招式名` | 例：`@破壞光線` |
| `@屬性` | 例：`@火` |
| `@1` / `@2` / `@3` | 普通招式／第一特殊／第二特殊 |
| `@天氣` | 當下受天氣加成的 |
| `@特別` | 有絕版招式的 |
| `!@move` | 有第二特殊招式的 |

單獨打屬性名（例：`冰`）是篩屬性，不是招式。

### 運算符

| 符號 | 意思 |
| --- | --- |
| `,` `:` `;` | 或（OR） |
| `&` `\|` | 且（AND） |
| `!` | 反向（**半形**驚嘆號） |

範例：

```
@龍尾&@流星群          同時有這兩個招式
1,4,7&異色             一代御三家而且是異色
快龍,傳說的寶可夢&cp2000-   （快龍或神獸）而且 CP 2000 以上
@龍尾&!@流星群         有龍尾但沒有流星群
```

## 跟這個專案的落差

真的要做「把交換清單變成搜尋字串」的話，先知道這三件事：

1. **裝扮表達不出來。** 只有 `特殊`（有裝扮）這一個字詞，指定不了是哪一個裝扮。
   我們有 303 個裝扮橫跨一百多個物種，那是這個站的差異化，字串裡會整個消失。
2. **背卡完全沒有對應的關鍵字。** 同上，而且更徹底——連「有背卡」都篩不了。
3. **極巨化與超極巨化沒有收。** 淨化與暗影有。這份的年代在那之前，
   不代表遊戲裡真的沒有，要實測。

編號區間與 `,` 倒是很省字：一份清單的編號去重排序之後可以合併成
`25,133,143&異色` 這種，長度遠短於逐隻列名字。
