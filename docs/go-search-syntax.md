# GO 搜尋語法參考（三語對照）

> **這份是外部資料的整理，不是本專案的規格。** 程式沒有用到它，
> 收在這裡是為了之後要做「產生搜尋字串」之類的功能時不必重查。

⚠️ **三語不是互相翻譯，是各自獨立的字串**，而且未文件化的那些各語言落差最大
（日文社群清單裡甚至混著 `galar` 這種沒翻的）。**下面標「未確認」的欄位就是真的沒查到**，
不要照字面推一個出來——推錯的下場是使用者打了一個搜不到東西的字串。

⚠️ **抄來的語法沒有實測跟沒有資料是同一件事。** 真要拿來產字串之前逐條在遊戲裡打過。
這跟「只收確認在 GO 裡有的東西」是同一條原則。

## 跟這個專案的關係（先看這段）

**GO 的搜尋幾乎涵蓋了我們交換表的全部六個條件**：

| 我們的條件 | 搜尋關鍵字（繁中） | 能不能指定是哪一個 |
| --- | --- | --- |
| 異色 | `異色` | — |
| XXL / XXS | `XXL`／`XXS` | — |
| 淨化 | `淨化` | — |
| 極巨化 | `極巨化` | — |
| 超極巨化 | `超極巨化` | — |
| **背卡** | **`背卡`**（全部）／**`紀念背卡`**（實體活動的地點卡） | ❌ **只能篩有沒有，指定不了是哪一張** |
| （裝扮） | `特殊` | ❌ **只能篩有沒有，指定不了是哪一款** |

`背卡` = 官方英文的 `background`，`紀念背卡` = `locationbackground`，
社群另外記了一個 `specialbackground`（全球活動的特殊背景，官方頁沒收）。
**這正好對上我們 `bgdata.js` 的 `lc_`（地點卡）與 `sb_`（特殊背景）兩種**。

所以真正表達不出來的只剩兩件事，而它們正是這個站的差異化：
**哪一張背卡、哪一個裝扮**。搜尋字串只能把對方的箱子縮到「有背卡的皮卡丘」，
剩下的還是得看分享圖。

編號區間很省字：`25,133,143&異色` 比逐隻打名字短得多。

### 數值與範圍

寫法一律 `關鍵字下限-上限`，省略一邊就是開區間。

| 英文 | 繁體中文 | 日文 | 例 |
| --- | --- | --- | --- |
| `cp` | `CP` | `CP` | `CP300`、`CP200-300`、`CP300-`、`CP-300` |
| `hp` | `HP` | `HP` | 同上。算的是滿血值，不管現在受傷沒 |
| `distance` | `距離` | `きょり` | `距離1000`、`距離1000-1200` |
| `age` | `日數` | `日数` | `日數0` 是 24 小時內 |
| `year` | `年` | `年` | `年2016`；社群說兩位數 `年16` 也通 |
| `buddy0-5` | `夥伴0-5` | `相棒を選ぶ0-5` | 0 = 從沒當過夥伴 |
| `0-4*` | — | — | 評價星數，`4*` 是 IV 100 |
| `1attack` `2defense` `3hp` | 官方頁仍寫 `1Attack`／`2Defense`／`3HP` | `1こうげき` `2ぼうぎょ` `3HP` | 巴哈寫成「0-4攻擊」，**哪一種真的通要實測** |

IV 對照：0=0、1=1~5、2=6~10、3=11~14、4=15。
星數對照（IV 總和）：0=0~22、1=23~29、2=30~36、3=37~44、4=45。

### 招式

| 寫法 | 意思 |
| --- | --- |
| `@招式名` | 學會該招式的（自動補完，招式名有空格就照打） |
| `@屬性` | 學會該屬性招式的。**屬性優先於招式名** |
| `@1` `@2` `@3` + 屬性或招式 | 一般／第一特殊／第二特殊 |
| `@特別`（en `@special`／ja 官方寫 `@わざ`，可疑） | 招式學習器學不到的招式，含絕版招式、報恩與鬧脾氣 |
| `@天氣`（ja `@天候`） | 招式受當下天氣加成 |
| `!@mov` | 有第二特殊招式的（沒有的那些內部叫 `move_name_0000`） |
| `adventureeffect` | 招式帶探險效果的。**它前面不加 `@`**，社群標為 bug |

### 運算符

| 符號 | 意思 |
| --- | --- |
| `&` `\|` | 且 |
| `,` `:` `;` | 或 |
| `!` | 非，**要緊貼關鍵字，中間不能有空格** |
| `+名字` | 整個進化家族 |
| `-` | 範圍（前置=上限、後置=下限、中間=區間） |
| `<屬性` | 弱點是該屬性的（會被該屬性打到效果絕佳） |
| `>屬性` | 有招式能剋該屬性的 |

**`,` 綁得比 `&` 緊**——`A,B&C` 是 `(A 或 B) 且 C`。官方三語都沒講這件事，
但寫長字串時錯了就整串意思變掉。

## 陷阱（都來自社群，標了 bug 的）

- **`極巨化` 找的是「手上這隻是極巨化的」，不是「這隻可以極巨化」。**
  它其實是 `dynamax1-` 的捷徑，數字指的是解鎖了幾個極巨招式。
  要「能打 Max Battle 的全部」得用 `maxmove1-`。
  **這跟我們 `maxdata.js` 那份「可極巨化名單」不是同一件事**，別混。
- **地區搜尋排除不掉地區型**：`!阿羅拉` 排掉之後沒有辦法再取消排除；
  而且早期世代（關都～合眾）現在永久排除地區型。編號區間 `1-151` 跟 `關都` 不等價。
- **造型的伽勒爾太陽珊瑚被歸成城都**，社群標為 bug。
- **`!1HP` 這類否定對 IV 條件無效**，`!1HP` 等於 `1HP`。
- **`+名字` 放在 `@` 或 `#` 前面會回傳空的**；放在別的關鍵字後面則完全沒作用。
- **開著「顯示進化形」時 `@招式` 會被當成 `+招式`**（變成找名字）。
- **捷徑字會吃掉後面的字**：`極巨化`、`超極巨化`、`count` 都是範圍的捷徑，
  所以 `@Counter`、`@極巨炮` 這種搜尋會出問題。
- **名字裡有標點要照打**：`mr.` 找得到魔牆人偶，`mr mime` 找不到。
- 全部大小寫不敏感，名字與招式是**前綴自動補完**。
